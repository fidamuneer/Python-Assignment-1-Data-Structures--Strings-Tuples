# Python-Assignment-1-Data-Structures--Strings-Tuples

## Project Overview
This project is part of my Python fundamentals learning journey. It focuses on practicing basic Python concepts related to **strings and tuples**, including string manipulation, indexing, slicing, and tuple operations.

## Objectives
- Understand string concatenation and user input.
- Perform string indexing and slicing operations.
- Practice built-in string methods.
- Create, concatenate, repeat, and access tuple elements.

## Topics Covered

### 1. String Concatenation
- Accept a user's name as input.
- Concatenate strings to display a welcome message.
- Extend the message with additional text.

### 2. String Slicing and Indexing
- Access the first and last characters of a string.
- Extract the first five and last eleven characters.
- Reverse a string using slicing.
- Extract the word "Python" using slicing.

### 3. String Methods
- Convert a string to uppercase and lowercase.
- Use the `capitalize()` method.
- Count occurrences of a character using `count()`.
- Replace a word using the `replace()` method.

### 4. Tuple Operations
- Create two tuples.
- Concatenate tuples using the `+` operator.
- Repeat tuple elements using the `*` operator.
- Access individual elements using indexing.
- Extract elements using tuple slicing.

## Tools & Technologies
- **Programming Language:** Python
- **Concepts:** Strings, Tuples, Indexing, Slicing, Built-in Methods
- **Environment:** Python IDE or code editor

## Key Learnings
Through this assignment, I practiced fundamental Python operations and improved my understanding of string manipulation and tuple handling.
